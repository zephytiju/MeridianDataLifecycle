# Meridian Storage Projection

`meridian-storage-projection` is the Apache-2.0 Meridian V1 library for
projection, cache coordination, migration, logical portability, and rebuild
contracts. It is a shared lifecycle library and does not define a Catalog.

The repository is being bootstrapped against the released Meridian Core,
Semantics, and Query 1.0.0 contracts. Production APIs and conformance evidence
will be added through a protected-branch pull request.
